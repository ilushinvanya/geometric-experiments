# Математические дроби

https://ilushinvanya.github.io/geometric-experiments/fractions/

## Описание

Наглядное интерактивное пособие для изучения математических дробей в начальной школе.

Квадрат визуально представляет дробь:
- **Знаменатель** — на сколько частей разделён квадрат
- **Числитель** — сколько частей выбрано

## Управление

- **Разбить на части** — увеличивает деление квадрата (от 1 до 100 частей)
- **−** — уменьшает деление квадрата
- **Клик на часть** — выбирает/снимает выбор
- **Зажать и провести мышью** — быстрое выделение нескольких частей
